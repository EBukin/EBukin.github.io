## Key Design Decisions

1. Folder-per-item pattern: Each publication/project is a folder with index.qmd
2. Auto-CV: CV auto-generated from content frontmatter (single source of truth)
3. Featured flag: Use featured: true in frontmatter for landing page
4. Software section: Separate from projects, with type: r-package in frontmatter
5. Simple start: Begin with minimal styling, customize later

## Commands Reference

- Preview locally: `quarto preview`
- Render site: `quarto render`
- Check for issues: `quarto check`
